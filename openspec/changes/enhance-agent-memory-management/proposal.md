## Why

当前“我的长期记忆”页面仍按用户全局记忆展示，无法说明记忆属于哪个智能体，也无法在新增或编辑时选择有权限的智能体。用户看到的内容因此和实际生效的智能体上下文不一致，容易造成误用和误删。

## What Changes

- 将设置菜单名称从“我的长期记忆”调整为“记忆”。
- 使用智能体记忆作为页面数据源，列表展示“智能体”和“内容”两列。
- 新建、编辑时只允许选择当前用户有权限访问的智能体。
- 记忆编辑器支持展开为全屏，并提供明确的关闭按钮。
- 增加按当前用户和智能体权限隔离的查询、创建、更新、删除和清空接口。
- 保留现有自动记忆提取链路，手工维护的智能体记忆继续参与对应智能体对话上下文。

### Non-goals

- 不改变自动记忆提取模型和现有全局用户记忆接口的兼容性。
- 不新增跨租户共享记忆或管理员代用户编辑能力。

## Capabilities

### New Capabilities

- `agent-memory-management`: 管理当前用户有权限访问的智能体记忆。

### Modified Capabilities

- `user-long-term-memory-management`: 设置入口名称和页面数据模型改为智能体记忆。

## Impact

- 前端设置导航、记忆管理页面、React Query 服务和中英文文案。
- 后端 AI memory controller/service、DTO、智能体权限查询和用户隔离校验。
- 复用现有 `ai_agent_memory` 表，不需要迁移数据结构。
- 增加 API 权限隔离、CRUD 和前端关键交互测试。
