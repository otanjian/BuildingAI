## Purpose

Establishes **Bowi AI** as the single user-visible product name across the web app, PWA
install metadata, desktop window configuration, in-app copy, API-generated default
titles/descriptions, and CLI/deployment output, replacing the former "BuildingAI" branding.

## ADDED Requirements

### Requirement: Web metadata uses Bowi AI

The web app SHALL present "Bowi AI" as the product name in browser metadata and PWA install
metadata: the HTML document title, the PWA manifest `name` and `short_name`, and the manifest
`description`.

#### Scenario: Browser tab shows new name

- **WHEN** a user opens the web app in a browser
- **THEN** the tab title displays "Bowi AI"

#### Scenario: Android home-screen label

- **WHEN** a user adds the app to their home screen on Android/Chrome
- **THEN** the label under the icon reads "Bowi AI" (from manifest `short_name`)

#### Scenario: iOS home-screen label

- **WHEN** a user adds the app to their home screen on iOS
- **THEN** the label under the icon reads "Bowi AI" (from the document title fallback)

### Requirement: Desktop window title uses Bowi AI

The Tauri desktop application SHALL identify itself as "Bowi AI" in its product name and main
window title.

#### Scenario: Desktop app window

- **WHEN** a user launches the desktop app
- **THEN** the main window title displays "Bowi AI"

### Requirement: In-app copy uses Bowi AI

All user-visible in-app text that names the product SHALL read "Bowi AI" instead of
"BuildingAI", including the install flow welcome headline, the install success message, the
about dialog title, and agent decoration copy.

#### Scenario: Install welcome screen

- **WHEN** a user views the install welcome screen
- **THEN** the product headline reads "Bowi AI"

#### Scenario: About dialog

- **WHEN** a user opens the About dialog in the console
- **THEN** the dialog title reads "关于Bowi AI"

### Requirement: API-generated default names use Bowi AI

User-visible strings generated by the API SHALL use "Bowi AI": the default title for new
OpenCode conversations, the OpenCode agent system prompt product reference, console MCP
server descriptions, and the platform secret description.

#### Scenario: New conversation default title

- **WHEN** the API creates an OpenCode conversation without a custom title
- **THEN** the conversation default title reads "Bowi AI conversation"

#### Scenario: Console MCP server description

- **WHEN** the console MCP seed service registers the control-plane MCP server
- **THEN** its description references "Bowi AI"

### Requirement: CLI and deployment output uses Bowi AI

CLI and deployment tooling SHALL print "Bowi AI" when referring to the product by name in
predeploy output and docker-compose startup logs.

#### Scenario: Predeploy completion message

- **WHEN** the CLI predeploy finishes
- **THEN** the completion message names the project "Bowi AI"

#### Scenario: Container startup log

- **WHEN** the docker-compose entrypoint starts the container
- **THEN** the startup log line reads "Bowi AI"
