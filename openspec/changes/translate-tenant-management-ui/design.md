## Context

租户管理页当前直接在 JSX 中写入英文文案，且接口返回的状态值也直接展示。控制台的菜单和其他页面已经以中文为主，因此本次只调整展示层，不改变租户 API 合同。

## Goals / Non-Goals

**Goals:**

- 覆盖页面所有用户可见的英文静态文案。
- 对已知租户、成员、项目和策略状态提供稳定的中文标签。
- 保持现有交互、请求参数和权限校验不变。

**Non-Goals:**

- 不修改后端错误消息、数据库值或 API 字段。
- 不在本次变更中引入新的国际化框架或改造其他控制台页面。

## Decisions

- 在页面文件内集中定义状态翻译函数和角色翻译函数，避免把英文状态值直接渲染给用户。
- 使用中文默认回退值（例如“未知”“租户级别”），以便后端新增状态时页面仍保持中文可读。
- 使用测试可直接导入的纯函数验证映射，页面继续复用现有服务 hooks 和 UI 组件。

## Risks / Trade-offs

- [Risk] 后端新增状态未加入映射 → Mitigation：所有映射提供中文回退值，不会退回显示原始英文。
- [Risk] 页面仍有遗漏的英文文案 → Mitigation：对页面源文件执行英文文本扫描，并运行前端测试与 lint。
