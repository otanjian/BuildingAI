## Why

Bowi AI 已能从对话中自动提取并使用用户记忆，但用户目前只能在个性化设置中查看和删除记忆，无法主动纠正、补充或组织内容。新增独立的“我的长期记忆”菜单，让用户拥有清晰、可控的记忆管理入口，提升个性化回答的准确性与隐私透明度。

**Why now:** 记忆已经参与聊天提示词生成；若用户不能编辑错误或过时内容，错误会持续影响后续回答。

## What Changes

- 在前端设置导航中新增“我的长期记忆”菜单项。
- 展示当前登录用户的全局长期记忆，支持分页/加载、分类和更新时间展示。
- 支持用户手动新增、编辑、删除单条记忆，并提供清空全部记忆能力。
- 后端增加记忆详情、创建、更新、批量删除接口；所有操作强制按当前用户隔离。
- 保留现有自动抽取能力，并让手工修改后的内容可直接被后续对话使用。
- 增加表单校验、确认弹窗、错误提示、空状态和移动端适配。
- 记录记忆来源/更新时间等元数据，但不在界面暴露敏感内部标识。

### Non-goals

- 本次不实现向量检索、跨租户共享记忆或 Agent 专属记忆管理页面。
- 本次不改变现有记忆抽取模型和计费策略。

## Capabilities

### New Capabilities

- `user-long-term-memory-management`: 用户查看、创建、编辑、删除和清空个人长期记忆。

### Modified Capabilities

- 无。

## Impact

- 前端：设置导航、长期记忆管理页面、React Query 服务和中英文文案。
- 后端：AI memory controller/service、DTO、鉴权校验和 TypeORM 查询。
- 数据库：复用 `ai_user_memory` 表，仅在必要时增加更新时间/来源展示字段，不新建表。
- 测试：API 用户隔离与 CRUD 测试、前端交互和类型检查。
