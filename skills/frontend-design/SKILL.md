# Frontend Design

Before coding, identify the user, purpose, existing design system, technical constraints, and one memorable visual idea. If the project already has brand tokens or components, preserve them.

## Defaults

- Make the interface functional, accessible, responsive, and visually cohesive.
- Use CSS variables/tokens for color and spacing; choose typography for readability and context.
- Use motion selectively for hierarchy and feedback, respecting reduced-motion preferences.
- Use asymmetry, texture, overlap, or density only when they support the product context.
- Avoid uncontextualized template UI, generic copy, repetitive cards, purple-gradient defaults, and arbitrary font choices. These are defaults, not reasons to override an existing product system.
- Match implementation complexity to the requested scope; a small style fix should not become a visual rewrite.
